Design Process & Timeline

Design Thinking Process

We have followed different steps of Design Thinking process so that we can provide a solution-based approach to solving problems. Empathise, Define, Ideate, Prototype, and Test are five different stages of Design Thinking.

01-Empathise
  • User Research
  • Observation
  • Empathy Mapping
02-Define
  • User Persona
  • User Journey Map
  • Competitive Analysis
  • Problem Statement
  • Hypothesis
03-Ideate
  • Brain Storming
  • User Flow
  • Sitemap
04-Prototype
  • Sketch
  • Wireframe
  • Prototype
  • Style Guide
  • Visual Design
05-Test
  • Usability Testing
